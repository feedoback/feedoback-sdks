# Feedoback SDKs

Feedback from inside your app or site, filed next to everything else your
visitors send. [feedoback.com](https://feedoback.com)

| Package | Install | Source |
|---|---|---|
| iOS | Swift Package Manager: `https://github.com/feedoback/feedoback-ios` | [feedoback-ios](https://github.com/feedoback/feedoback-ios) |
| Android | `implementation("com.feedoback:feedoback-android:<version>")` | [android](android) |
| React Native | `npm install feedoback-react-native` | [react-native](react-native) |
| Flutter | `flutter pub add feedoback_flutter` | [feedoback_flutter](feedoback_flutter) |
| React and Next.js | `npm install feedoback-react` | [react](react) |

Each package has its own README, changelog and version.

## Issues

This repository is where problems with any of the SDKs are reported,
including the iOS one. Open an issue here.

## Pull requests

The SDKs are developed alongside the Feedoback service and copied here on
each release, so this repository is rebuilt rather than edited and a pull
request against it would be overwritten. Describe the change in an issue
instead.
